# Жизнь в балансе ⚖️

Локальный веб-трекер привычек: ежедневный чек-лист здорового и продуктивного образа жизни.

- ✅ чек-лист действий с весами (баллы за выполнение)
- 📊 баллы за день, оценка A/B/C/D
- 🔥 серия дней подряд
- 📈 график прогресса за 7 / 14 / 30 дней
- 🛠 редактирование, добавление и удаление своих действий
- 💾 все данные хранятся локально в браузере (localStorage)

## Запуск

Просто откройте `index.html` в браузере — сервер не нужен.

## Файлы

- `index.html` — разметка
- `styles.css` — стили
- `app.js` — логика приложения
